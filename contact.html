Contact

If you need help, want to report a problem, or have a suggestion for improving Diagram Editor, you can reach out through our public issue tracker.

Report an Issue

The preferred way to contact the project is by opening an issue on GitHub:

Project Issue Tracker
https://github.com/ballr73/diagram/issues

You can use the issue tracker to:

  • report bugs
  • request new features
  • ask questions
  • share feedback
  • suggest improvements

Issues are reviewed regularly, and responses are typically provided as soon as possible.

Why GitHub Issues?

Using GitHub for support ensures that:

  • all feedback is tracked in one place
  • bugs and feature requests are easy to organise
  • other users can follow discussions and solutions
  • fixes and improvements can be linked directly to code changes

This helps keep the project transparent, organised, and easy to maintain.
