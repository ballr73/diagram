Diagram App

A fast, lightweight browser-based diagramming tool

What is Diagram App?

Diagram App is a free, browser-based SVG diagramming tool built for engineers, architects, and teams who need to create clear, professional diagrams without installing software or signing up for an account.

The editor runs entirely client‑side — your diagrams never leave your browser. No accounts, no data collection, no storage — just a fast, lightweight interface for creating AWS, Azure, GCP, and custom diagrams.

Supported Diagram Types

Diagram App ships with a curated icon library covering the major cloud providers and custom shapes:

AWS Azure GCP Custom shapes

Use it to create:

  • AWS architecture diagrams
  • Azure solution diagrams
  • GCP infrastructure diagrams
  • System and network diagrams
  • Flowcharts and process flows
  • Custom multi-service diagrams
  • Multi-tab diagram workspaces
  • Annotated region diagrams

Key Features

  • Drag-and-drop icon library
  • Smart connectors with waypoints
  • Text annotations and region boxes
  • Multiple tabs per diagram
  • Zoom, pan, and fit-to-window
  • Align and distribute tools
  • Bring to front / send to back
  • Label position control
  • Shape opacity control
  • Undo / redo history
  • Save & open JSON diagrams
  • Export to PNG and SVG
  • Keyboard shortcuts throughout
  • Runs 100% in your browser
