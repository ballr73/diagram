What Is It?

Diagram App is a free, browser-based diagramming tool that lets you create professional technical diagrams without installing any software. It runs entirely in your browser — open a file or start from scratch in seconds. Your work is saved locally as a .json file or synced to Google Drive, keeping your data private and always accessible.

Whether you need to sketch a cloud architecture diagram for AWS, Azure, or GCP, map out a network topology, document a software system design, or build a flowchart for a business process, Diagram App gives you the tools to do it quickly and cleanly. Export finished diagrams as SVG or PNG for presentations, wikis, or documentation.

Features

🏗 Built-in Shape Library

Box, circle, diamond, triangle, parallelogram, document, database, wait, merge — all standard flowchart and diagram shapes.

🔗 Smart Connectors

Drag connectors between shapes. Add waypoints, choose curved or straight routing, and drag anchor points anywhere on a shape's border.

☁️ Cloud & Tech Icons

Hundreds of icons for AWS, Azure, GCP, and general networking — drag and drop to build cloud architecture diagrams instantly.

📐 Layers

Organise complex diagrams into layers. Toggle visibility, lock layers, reorder by drag-and-drop, and control Z-ordering per layer.

📊 Multi-Tab Diagrams

One file, multiple pages. Create separate tabs for different views — great for layered architecture documentation.

🎬 Presentation Mode

Present diagrams fullscreen with all UI hidden. Navigate between tabs with arrow keys or on-screen controls.

💾 Google Drive

Open and save diagrams directly to Google Drive. Browse folders and keep diagrams in sync across devices.

🖼 Export SVG & PNG

Export crisp, high-resolution diagrams as scalable SVG or retina-ready PNG — perfect for slides, docs, or print.

⚙️ Full Styling Control

Per-element fill, stroke, opacity, font, dash style, label position, and arrow direction. Powerful without being complex.
